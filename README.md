# Real Time Caption Companion

Live captions that work like subtitles.

A caption strip that floats over slides, code, or video. Stable, in step with the speaker, easy to read for a full lecture.

Every word, in writing. The full session transcript builds here as the lecture runs, ready to export when it ends.

What Caption+ does differently

Stable

Nothing you have read changes or jumps. Captions you can trust your eyes with, for a full lecture.

Technical

Course vocabulary comes out right: malloc stays malloc, in the lectures where terms matter most.

Readable

A steady rhythm that keeps pace with the speaker, so you stay with the lecture instead of falling behind it.
